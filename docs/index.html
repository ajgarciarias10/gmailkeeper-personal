La idea

Lo que pedimos al correo,
en tres pasos.

01

Identificar

Agrupa los remitentes de una marca por dominio o por tus reglas personales. Aprende nombres cuando el remitente y el dominio coinciden.

02

Etiquetar

Crea subetiquetas de marca dentro de cada categoría. Añade las que faltan y conserva las que ya tenías.

03

Archivar

Retira el mensaje de Recibidos. Sigue disponible en Gmail, con el mismo estado de lectura. Si la marca no se reconoce, queda pendiente.

De la idea a tu cuenta

Una guía para probarlo
con tu propio Gmail.

El proyecto requiere conocimientos técnicos: Python 3.10 o posterior, Git y tu propio cliente OAuth de Google. La configuración y las credenciales se guardan en tu ordenador.

1

Descarga el proyecto

Crea un entorno Python e instala la dependencia de autenticación.

Guía de instalación →
2

Define tus reglas y conecta Gmail

Conexión paso a paso →
3

Revisa antes de aplicar

La vista previa muestra hasta 50 mensajes recientes sin modificar Gmail. Después aplica y comprueba el resultado.

4

Programa el mantenimiento

Automatización en los tres sistemas →
● ● ●Primeros pasos · Linux / macOS
# Descarga
git clone https://github.com/ajgarciarias10/gmailkeeper-personal.git
cd gmailkeeper-personal

# Entorno e instalación
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt

# Configuración de tu cuenta
python gmailkeeper.py init \
  --account tu-correo@gmail.com

En Windows, la guía incluye los comandos de PowerShell y CMD. Configura tus preferencias antes de aplicar cambios.

Elige bien el alcance. La configuración predeterminada archiva todo lo recibido, incluidos avisos y facturas. Excluye enviados, borradores, chats, spam y papelera. Si prefieres solo promociones, configura ese caso antes de aplicar.

Qué conviene saber

Un proyecto pequeño.
Con sus límites claros.

¿De quién es la idea y qué licencia tiene?

Idea original: ajgarciarias10. El código y la documentación se publican bajo licencia MIT: puedes usarlos, modificarlos y compartirlos conservando el aviso de copyright y la licencia.

¿Qué datos utiliza?

Consulta remitentes y etiquetas. No descarga cuerpos ni adjuntos. Las credenciales, muestras y estado se guardan localmente; el registro público de marcas empieza vacío. Esta página no pide acceso al correo ni utiliza analítica.

¿Funciona con el ordenador apagado?

Los filtros ya creados siguen funcionando dentro de Gmail. Descubrir marcas nuevas, cubrir nuevas combinaciones de categoría y marca o revisar el histórico requiere ejecutar el programa en tu ordenador.

¿Tiene coste?

El proyecto no tiene suscripción ni necesita un servidor contratado o llamadas a IA. El uso de los servicios de Google está sujeto a sus cuotas y condiciones. Consulta los detalles y la fuente oficial en coste y privacidad.

¿Puede equivocarse con una marca?

Sí. La detección utiliza reglas y coincidencias entre nombres y dominios; no conoce todas las empresas. Puedes corregir nombres con reglas privadas o desactivar el aprendizaje automático. Los remitentes personales quedan pendientes salvo que los configures.

¿Cómo lo detengo?

Desactiva la tarea local y elimina los filtros creados por el perfil con las instrucciones de la guía. Se conservan los mensajes, las etiquetas y los filtros anteriores. El correo archivado no vuelve automáticamente a Recibidos.
